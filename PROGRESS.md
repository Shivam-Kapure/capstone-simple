## Architecture
- **Browser → frontend (nginx) → backend (FastAPI).** The browser only ever calls the frontend's own origin. nginx proxies `/api/*` and `/health` to `BACKEND_URL`: `http://backend:8000` in Compose and `http://capstone-backend:8000` in Kubernetes. So the browser never has to resolve a cluster-internal DNS name, and no CORS is needed. `CORS_ORIGINS` exists only as an optional env var.
- **Backend API:**
  - `GET /`, `GET /health`
  - `GET /api/payments`, `GET /api/payments/{id}` (404 if missing)
  - `POST /api/payments` (201 on success; 422 for bad amount, payer, currency or missing fields)
  - `GET /api/notifications`
  - Data is in memory: 3 seeded demo payments. No real payment processing.
